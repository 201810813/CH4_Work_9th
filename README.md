# CH4_Work_9th

## 멀티플레이 가능한 숫자 야구 게임.


- 기존의 제가 만들던 과제는 완성하지 못했습니다... BlueprintFucntionLibrary로 함수를 만들어 BP노드를 사용해 구현하려 했지만 네트워크에 대한 이해도가 부족했던 탓에 두번 출력 된다거나 등등 오류가 많았습니다.
- 부끄럽지만 해설 영상을 보면서 따라하는 것 뿐이지만. 그래도 이번 기회에 네트워크 이해도가 많이 나아진 것 같습니다..

### 구현 기능
1. 랜덤한 숫자 3개 생성
   - 중복 방지
   - '0' 제외
     
2. 야구 게임
   - 채팅이 숫자 3자리가 아니면 그냥 채팅 기능
   - 숫자 3개일 때 처리 -> CurrentAttempt가 상승(구현) MaxAttempt가 되면 게임 불가(구현 예정).
